# Paweł Ozga

I like working with small teams, getting to the bottom of a user problem, and shipping the simplest thing that solves it. Lately I’ve been building tools to make AI agents easier to test and run.

## Selected work

- **[AgentSpec](https://github.com/Ozperium/agentspec)** — A TypeScript CLI for testing AI agents. Write what you expect in YAML, run it against your agent, and [see what changed](https://github.com/Ozperium/agentspec#accepted-baselines-and-regression-diffs) when behaviour regresses.
- **[Stoke](https://github.com/Ozperium/stoke)** — A Rust gateway that gives me one endpoint for local and cloud models and caps spending when an agent runs away. I designed the gateway, set the acceptance criteria, and tested the agent-written implementation.
- **[mcp-profile](https://github.com/pozga/mcp-profile)** — A small tool for switching between named sets of MCP servers in Claude Code.
